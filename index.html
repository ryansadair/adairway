Look up a course

Pulls par, yardage, rating & slope from OpenGolfAPI's free public course database — a plain data lookup, no account, nothing sent about you. It's community-maintained (like a wiki), so double-check anything that looks off.

Add course notes

Only courses with par data show up in the Rounds/Play quick-load dropdown — "Look up a course" above fills this in automatically, or enter it yourself below.
Tip: re-entering a course name you've already saved updates that course instead of duplicating it — handy for adding par to a course you added before this field existed.

Export a backup

Downloads everything — rounds, practice log, bag, course notes, journal — as one JSON file. Save it to Google Drive, Files, email it to yourself, wherever. This browser's storage is durable for normal use, but this file is your safety net if anything ever gets cleared.

Restore from a backup

Picks up a backup file you exported earlier and replaces everything currently in this browser with it. Use this if you're setting up on a new phone/browser, or recovering after data got cleared.
